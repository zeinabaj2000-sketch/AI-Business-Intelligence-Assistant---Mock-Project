# DEXCR — AI Business Intelligence Assistant

An AI-powered Business Intelligence Assistant designed to help users explore business performance through natural-language questions and data-driven analysis.

## Project Overview

DEXCR combines Python-based analytics, financial and sales datasets, and a language model to provide accessible business insights.

The application aims to help users:
- Analyze sales performance by category, channel, and customer segment.
- Explore revenue, profitability, and financial KPIs.
- Examine monthly business trends.
- Ask business questions in natural language.
- Inspect the underlying results supporting the assistant's responses.

## Technology Stack

- **Python** — data processing and analytics
- **Pandas and NumPy** — data manipulation
- **Streamlit** — interactive web application
- **Hugging Face Transformers** — language model integration
- **GitHub** — version control and project management
- **Streamlit Community Cloud** — application deployment

## Data Sources

The initial prototype uses four datasets:

- `sales_transactions.csv`
- `daily_drivers.csv`
- `monthly_financials.csv`
- `data_dictionary.csv`

These datasets support sales analysis, financial reporting, and operational exploration.

## Project Status

Initial development: data analysis, Python business tools, language-model integration, and Streamlit interface.

## Important Notes

- Financial calculations depend on the definitions and quality of the source data.
- The initial assistant supports a defined set of analytical tools.
- The current sales dataset contains product categories rather than individual product names.
- Never commit confidential business information, credentials, API keys, or sensitive customer data to a public repository.
